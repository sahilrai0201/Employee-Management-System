# SAP ABAP RAP OData V4 Service Deployment Guide

This guide explains how to deploy the backend services for the **Employee Management** application in SAP S/4HANA (on-premise or Private Cloud 2020+) or SAP BTP ABAP Environment (Steampunk).

---

## 1. Database Table Definition (`zemployee`)

In **ABAP Development Tools (ADT)**, create a database table named `zemployee`:

```sql
@EndUserText.label : 'Employee Master Data'
@AbapCatalog.enhancement.category : #NOT_EXTENSIBLE
@AbapCatalog.tableCategory : #TRANSPARENT
@AbapCatalog.deliveryClass : #A
@AbapCatalog.dataMaintenance : #RESTRICTED
define table zemployee {
  key client            : mandt not null;
  key employee_id       : abap.char(10) not null;
  first_name            : abap.char(40) not null;
  last_name             : abap.char(40) not null;
  email                 : abap.char(100) not null;
  phone_number          : abap.char(30);
  date_of_birth         : abap.dats;
  department            : abap.char(50) not null;
  job_title             : abap.char(60) not null;
  manager               : abap.char(80);
  joining_date          : abap.dats not null;
  employment_type       : abap.char(20) not null;
  employment_status     : abap.char(20) not null;
  office_location       : abap.char(50);
  @Semantics.amount.currencyCode : 'zemployee.currency'
  salary                : abap.curr(13,2);
  currency              : abap.cuky;
  
  // Administrative fields for ETag and Audit Trail
  created_by            : syuname;
  created_at            : timestampl;
  last_changed_by       : syuname;
  last_changed_at       : timestampl;
  local_last_changed_at : timestampl;
}
```

---

## 2. Activate Artifacts in Order

Deploy the artifacts in the following sequence in ADT:

1. **Table**: `zemployee` and draft table `zemployee_d` (auto-generated by RAP).
2. **Interface View**: `ZI_Employee.cds`
3. **Consumption View**: `ZC_Employee.cds` (Contains `@UI` lineItem, selectionFields, headerInfo, facets, fieldGroups)
4. **Behavior Definition**: `ZI_Employee.bdef` (RAP Managed with Draft and validations)
5. **Behavior Implementation**: `zbp_i_employee.clas.abap` (Duplicate ID check, email check, salary check)
6. **Projection Behavior Definition**: `ZC_Employee.bdef`
7. **Service Definition**: `ZSD_EMPLOYEE.srvd`
8. **Service Binding**: `ZUI_EMPLOYEE_O4` (Binding Type: **OData V4 - UI**)

---

## 3. Publish Service Binding

1. In ADT, open the Service Binding **`ZUI_EMPLOYEE_O4`**.
2. Click the **Publish** button.
3. Once published, note the service URL:
   ```
   /sap/opu/odata4/sap/zui_employee_o4/srvd/sap/zsd_employee/0001/
   ```
4. Double-click the entity set **`Employee`** in the Service Binding preview to test the OData V4 service in the browser or Fiori Elements Preview.

---

## 4. Connecting the Frontend Application

In `webapp/manifest.json`, the data source is configured as:

```json
"sap.app": {
  "dataSources": {
    "mainService": {
      "uri": "/sap/opu/odata4/sap/zui_employee_o4/srvd/sap/zsd_employee/0001/",
      "type": "OData",
      "settings": {
        "annotations": ["annotation"],
        "odataVersion": "4.0"
      }
    }
  }
}
```

In `ui5.yaml`, configure the backend destination for SAP BTP or SAP S/4HANA:

```yaml
server:
  customMiddleware:
    - name: fiori-tools-proxy
      afterMiddleware: compression
      configuration:
        backend:
          - path: /sap
            url: https://your-s4hana-host:port
            destination: S4HANA_DESTINATION
```
